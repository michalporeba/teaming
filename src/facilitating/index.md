The aim is that anyone can run a standard session reliably, without first designing an exercise or building tooling — and, with experience, adapt the sessions or create their own.

## Shared practices

These are used by more than one workshop.

- [The cards exercise](/facilitating/cards-exercise/) — a no-code opener contrasting separable work with shared decisions.
- [Shared AI operating model](/facilitating/shared-ai/) — roles, a decision loop and a working agreement for a team using one coding agent.

## Running and developing the programme

- [Piloting](/facilitating/piloting/) — the first pilot sequence, what to prepare and what to observe.
- [Training facilitators](/facilitating/training/) — scripted sessions and a pathway to running the workshops independently.
